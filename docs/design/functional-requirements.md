# 기능 요구사항

## FR-001: 사용자 로그인
- 우선순위: High
- 작성일자: 2026-08-26
- 설명: 사용자는 이메일과 비밀번호로 로그인할 수 있다.

### 수용 기준
- [ ] 유효한 사용자 정보를 입력하여 로그인에 성공한 경우 홈 화면으로 이동한다.
- [ ] 잘못된 사용자 정보를 입력한 경우 에러 메시지를 표시한다.

## FR-002: 사용자 가입
- 우선순위: High
- 작성일자: 2026-08-26
- 설명: 사용자는 자신이 사용할 정보를 입력하여 서비스 사용을 위한 자격을 얻을 수 있다.

### 수용 기준
- [ ] 사용자의 이메일, 비밀번호 정보를 입력받는다.
- [ ] 입력한 이메일이 유효하지 않거나 중복되는 경우 에러 메시지를 표시한다.
- [ ] 입력한 비밀번호가 영대소문자, 숫자를 포함하여 8자리 이상이 아닌 경우 에러 메시지를 표시한다.
- [ ] 입력받은 데이터가 모두 유효한 경우 성공한 후 로그인 화면으로 이동한다.

## FR-003: 지도와 단지별 핀 표기
- 우선순위: High
- 작성일자: 2026-08-26
- 설명: 사용자가 로그인에 성공 후 진입하는 홈 화면으로 상단에는 단지를 검색할 수 있는 간단한 검색 창이 존재한다. 우측에는 지도 그리고 단지별 핀과 평균 실거래가를 확인할 수 있다.

### 수용 기준
- [ ] 검색창에서 입력한 단지가 확인된 경우 해당 핀을 정중앙으로 지도를 이동시킨다.

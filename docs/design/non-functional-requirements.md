# 비기능 요구사항 (ISO/IEC 25010 기준 분류 2023년 기준)

## 핵심 품질 모델 특성

- 기능 적합성(Functional Suitability): 제품 또는 시스템이 특정 조건에서 사용될 때 명시적 및 묵시적 요구 사항을 충족하는 기능을 제공하는 정도
- 성능 효율성(Performance Efficiency): 명시된 조건에서 사용된 자원량 대비 성능
- 호환성(Compatibility): 제품, 시스템 또는 구성 요소가 동일한 하드웨어 또는 소프트웨어 환경을 공유하면서 다른 제품, 시스템 또는 구성 요소와 정보를 교환하고 필요한 기능을 수행할 수 있는 정도
- 상호 작용 기능(Interaction Capability): 제품이나 시스템을 특정 사용자가 특정 사용 환경에서 특정 목표를 효과적이고 효율적이며 만족스럽게 달성할 수 있도록 조작할 수 있는 정도
- 신뢰성(Reliability): 시스템, 제품 또는 구성 요소가 특정 조건 하에서 특정 기간 동안 특정 기능을 수행하는 정도
- 보안성(Security): 제품 또는 시스템이 정보와 데이터를 보호하는 정도
- 유지보수성(Maintainability): 제품이나 시스템을 의도된 유지 관리자들이 얼마나 효과적이고 효율적으로 수정할 수 있는지의 정도
- 유연성(Portability): 제품이나 시스템이 다양하거나 진화하는 하드웨어, 소프트웨어 또는 기타 운영/사용 환경에 적응할 수 있는 정도
- 안전성(Safety): 특정 사용 환경에서 제품이나 시스템이 사람, 기업, 소프트웨어, 재산 또는 환경에 해를 끼치지 않는 정도

## 성능 효율성
- NFR-001: API 응답 시간 (P95 300ms 이하)
- NFR-002: 동시 접속자 처리 (초당 100건)
